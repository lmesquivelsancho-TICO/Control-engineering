Steady-state error for three test inputs

For the unity-feedback system with

\[G(s)=\frac{450(s+8)(s+12)(s+15)}{s(s+38)(s^2+2s+28)}\]

find the steady-state errors for the inputs \(25u(t)\), \(37tu(t)\) and \(47t^2u(t)\).

Nise, chapter 7, problem 1, p. 373. Section 7.2.

The three constants, and what they are good for

For a unity-feedback loop \(E(s)=\dfrac{R(s)}{1+G(s)}\), and the final value theorem turns each input into one limit. The type of the system is simply the number of pure integrators \(1/s\) in \(G(s)\), and it decides which of the three constants is finite.

InputR(s)Constante(∞)finite when
step \(Au(t)\)\(A/s\)\(K_p=\lim_{s\to0}G(s)\)\(\dfrac{A}{1+K_p}\)always (zero if type ≥ 1)
ramp \(Atu(t)\)\(A/s^2\)\(K_v=\lim_{s\to0}sG(s)\)\(\dfrac{A}{K_v}\)type ≥ 1
parabola \(At^2u(t)\)\(2A/s^3\)\(K_a=\lim_{s\to0}s^2G(s)\)\(\dfrac{2A}{K_a}\)type ≥ 2

Watch the factor of 2 in the parabola row: \(\mathcal{L}\{t^2\}=2/s^3\), so \(47t^2u(t)\) becomes \(94/s^3\).

Walkthrough

The final value theorem only gives a meaningful answer if the response actually converges, so the closed loop must be stable before anything else. Its characteristic polynomial is numerator plus denominator:

\[s(s+38)(s^2+2s+28)+450(s+8)(s+12)(s+15)=s^4+490s^3+15854s^2+179264s+648000\]

The Routh first column is \(1,\;490,\;15854,\;179264,\;648000\) — no sign changes, so the system is stable and the limits below are trustworthy.

From the block diagram, \(E=R-C\) and \(C=EG\), so

\[E(s)=R(s)-E(s)G(s)\;\Rightarrow\;E(s)=\frac{R(s)}{1+G(s)},\qquad e(\infty)=\lim_{s\to0}\frac{sR(s)}{1+G(s)}\]
\[e_{step}(\infty)=\lim_{s\to0}\frac{s\cdot\frac{25}{s}}{1+G(s)}=\frac{25}{1+K_p}\]

\(G\) has a factor \(s\) in its denominator, so \(K_p=\lim_{s\to0}G(s)=\infty\) and the error is zero. In the limit expression this shows up as an \(s\) surviving in the numerator after clearing fractions.

\[e_{ramp}(\infty)=\frac{37}{K_v},\qquad K_v=\lim_{s\to0}sG(s)=\frac{450\cdot8\cdot12\cdot15}{38\cdot28}=609.02\]
\[e_{ramp}(\infty)=\frac{37\cdot38\cdot28}{450\cdot8\cdot12\cdot15}=6.075\times10^{-2}\]

The output tracks the ramp with the same slope but stays a fixed distance behind it — that distance is the error.

\[K_a=\lim_{s\to0}s^2G(s)=\lim_{s\to0}s\cdot\frac{450\cdot8\cdot12\cdot15}{38\cdot28}=0\;\Rightarrow\;e_{par}(\infty)=\frac{94}{K_a}=\infty\]

One integrator is not enough to follow an accelerating input: the gap grows without limit.

All three answers follow from one observation: \(G\) has exactly one pole at the origin, so this is a type 1 system. Type 1 means zero error to a step, a finite error to a ramp, and infinite error to a parabola — you only need to compute \(K_v\).

Result
\[e_{step}(\infty)=0,\qquad e_{ramp}(\infty)=6.075\times10^{-2},\qquad e_{par}(\infty)=\infty\]

Steady-state error with non-unity feedback

For the system shown, find the steady-state error for inputs \(50u(t)\), \(50tu(t)\) and \(50t^2u(t)\), and state the system type.

Nise, chapter 7, problem 13b,c, p. 374. Section 7.3.

Walkthrough

“Error” always means \(E=R-C\), the difference between what you asked for and what you got. The extra \((s+3)\) path does not change that definition — it changes the system that sits between \(E\) and \(C\).

So the plan is: collapse everything inside the outer unity loop into one block \(G_e(s)\), then use the familiar \(E=R/(1+G_e)\).

Forward path \(\frac{5}{s(s+1)(s+2)}\), feedback \((s+3)\), negative sign:

\[G_e(s)=\frac{\frac{5}{s(s+1)(s+2)}}{1+\frac{5(s+3)}{s(s+1)(s+2)}}=\frac{5}{s(s+1)(s+2)+5(s+3)}=\frac{5}{s^3+3s^2+7s+15}\]

Closing the outer unity loop gives the characteristic polynomial \(s^3+3s^2+7s+15+5=s^3+3s^2+7s+20\). Routh: \(1,\;3,\;\frac{21-20}{3}=0.333,\;20\) — all positive, so the system is stable (but only just: raising the feedback gain would flip that third entry).

Notice what the inner loop did to the integrator: \(s(s+1)(s+2)+5(s+3)\) has a constant term 15, so there is no pole at the origin any more. The equivalent system is type 0:

\[K_p=G_e(0)=\frac{5}{15}=\frac13,\qquad e_{step}(\infty)=\frac{50}{1+\frac13}=37.5\]

Only \(12.5\) of the requested 50 ever arrives at the output.

\[K_v=\lim_{s\to0}sG_e(s)=0\;\Rightarrow\;e_{ramp}(\infty)=\infty,\qquad K_a=0\;\Rightarrow\;e_{par}(\infty)=\infty\]

A type 0 system: finite error to a step, infinite error to anything faster. The feedback path swallowed the free integrator that the forward path had.

Result
\[e_{step}(\infty)=37.5,\qquad e_{ramp}(\infty)=\infty,\qquad e_{par}(\infty)=\infty,\qquad\text{type }0\]

Lab: who decides the error?

The feedback block is \((s+a)\) and the forward gain is \(K\). Push both. The surprise is that \(K\) drops out of the steady-state error entirely: \(K_p=K/(Ka)=1/a\), so only the DC gain of the feedback path matters.

On the posted solution

It reduces the loop exactly this way and gets \(37.5\). Worth spelling out is why a system whose forward path contains \(1/s\) still ends up type 0: the type is a property of the equivalent \(G_e\) seen by the error signal, not of the forward block alone.

Choosing K to hit a required error

For the unity-feedback system with

\[G(s)=\frac{K(s+3)}{s^2(s+7)}\]

find \(K\) so that the steady-state error for the input \(10t^2u(t)\) is 0.061.

Nise, chapter 7, problem 21, p. 375. Section 7.4.

Walkthrough

\(G\) has \(s^2\) in the denominator: two integrators, so the system is type 2 and a parabolic input gives a finite error. The relevant constant is the acceleration constant:

\[K_a=\lim_{s\to0}s^2G(s)=\lim_{s\to0}\frac{K(s+3)}{s+7}=\frac{3K}{7}\]

\(r(t)=10t^2u(t)\) has \(R(s)=\frac{20}{s^3}\) — again the factor 2 from \(\mathcal{L}\{t^2\}=2/s^3\):

\[e(\infty)=\lim_{s\to0}\frac{s\cdot\frac{20}{s^3}}{1+G(s)}=\frac{20}{K_a}=\frac{20\cdot7}{3K}=\frac{140}{3K}\]
\[\frac{140}{3K}=0.061\;\Rightarrow\;K=\frac{140}{3(0.061)}=765.03\]

A large gain is only useful if the loop stays stable. The characteristic polynomial is

\[s^2(s+7)+K(s+3)=s^3+7s^2+Ks+3K\]

with Routh first column \(1,\;7,\;\frac{7K-3K}{7}=\frac{4K}{7},\;3K\): positive for every \(K>0\). So this loop is stable for any positive gain and \(K=765\) is fine. The lab shows the error settling on 0.061 — after a fairly violent transient.

Result
\[K_a=\frac{3K}{7},\qquad e(\infty)=\frac{140}{3K}=0.061\;\Rightarrow\;K=765.03\]

System type and the errors that follow from it

For the unity-feedback system with

\[G(s)=\frac{K(s^2+6s+6)}{(s+5)^2(s+3)}\]

(a) find the system type, (b) the error for \(12u(t)\), (c) the error for \(12tu(t)\).

Nise, chapter 7, problem 23, p. 375. Section 7.3.

Walkthrough

There is no \(1/s\) factor: every pole of \(G\) is at \(-5,\,-5,\,-3\). Type 0. That single observation already answers (c).

\[K_p=G(0)=\frac{K\cdot6}{25\cdot3}=0.08K\]
\[e_{step}(\infty)=\frac{12}{1+K_p}=\frac{12}{1+0.08K}\]

The answer is a function of \(K\), not a number: that is the honest answer to (b). For \(K=100\), for instance, the error is \(12/9=1.33\).

\(K_v=\lim_{s\to0}sG(s)=0\), so

\[e_{ramp}(\infty)=\frac{12}{K_v}=\infty\]

A type-0 system cannot follow a ramp at all: the output settles to a constant slope shortfall that accumulates for ever.

Result
\[\text{type }0,\qquad e_{step}(\infty)=\frac{12}{1+0.08K},\qquad e_{ramp}(\infty)=\infty\]

Designing for a steady-state error and a pole location at once

The unity-feedback system with

\[G(s)=\frac{K(s+\alpha)}{s(s+\beta)}\]

must have a steady-state error of \(1/10\) for a unit ramp, and closed-loop poles at \(-1\pm j1\). Find \(K\), \(\alpha\) and \(\beta\).

Nise, chapter 7, problem 29, p. 376. Section 7.4.

Walkthrough

The steady-state requirement gives one, and the pole location gives two (a complex pole fixes both the real and the imaginary part). That is exactly enough.

One integrator, so the system is type 1 and the ramp error is \(1/K_v\):

\[K_v=\lim_{s\to0}sG(s)=\frac{K\alpha}{\beta},\qquad e(\infty)=\frac{\beta}{K\alpha}=\frac{1}{10}\;\Rightarrow\;K\alpha=10\beta\]
\[T(s)=\frac{G}{1+G}=\frac{K(s+\alpha)}{s^2+(\beta+K)s+K\alpha}\]

The required poles \(-1\pm j1\) mean the denominator must be \((s+1)^2+1=s^2+2s+2\), i.e. \(\omega_n=\sqrt2\) and \(\zeta\omega_n=1\):

\[\beta+K=2\zeta\omega_n=2,\qquad K\alpha=\omega_n^2=2\]
\[K\alpha=2\;\text{and}\;K\alpha=10\beta\;\Rightarrow\;\beta=0.2\]
\[K=2-\beta=1.8,\qquad \alpha=\frac{2}{K}=1.111\]

\(K_v=\frac{1.8\times1.111}{0.2}=10\) ✓ and the closed-loop denominator is \(s^2+2s+2\) ✓, poles at \(-1\pm j1\).

The caveat: \(T(s)\) also has a zero at \(-\alpha=-1.111\), sitting right next to the poles. The pole positions are exactly as ordered, but the transient will overshoot more than a textbook second-order system with the same \(\zeta\) — a nearby zero always does that.

Result
\[K=1.8,\qquad \alpha=1.111,\qquad \beta=0.2\]

From a state-space model to a transfer function

Find \(G(s)=Y(s)/R(s)\) for

\[\dot{\mathbf x}=\begin{bmatrix}0&1&0\\0&0&1\\-3&-2&-5\end{bmatrix}\mathbf x+\begin{bmatrix}0\\0\\10\end{bmatrix}r,\qquad y=\begin{bmatrix}1&0&0\end{bmatrix}\mathbf x\]

Nise, chapter 3, problem 14a, p. 151. Section 3.6.

Walkthrough

Transform \(\dot{\mathbf x}=A\mathbf x+B r\) with zero initial conditions: \(s\mathbf X=A\mathbf X+BR\), so \((sI-A)\mathbf X=BR\) and

\[G(s)=C(sI-A)^{-1}B+D\]

Here \(D=0\). The inverse is \(\frac{1}{\det(sI-A)}\operatorname{adj}(sI-A)\), so the determinant becomes the denominator and the adjugate builds the numerator.

\[sI-A=\begin{bmatrix}s&-1&0\\0&s&-1\\3&2&s+5\end{bmatrix}\]

Expanding along the first row:

\[\det=s\big(s(s+5)+2\big)+1\big(0\cdot(s+5)+3\big)=s^3+5s^2+2s+3\]

Only the first row of \(\operatorname{adj}(sI-A)\) survives, because \(C=[1\;0\;0]\) picks it out, and only its third entry survives, because \(B\) has a single non-zero element in position 3:

\[\operatorname{adj}(sI-A)=\begin{bmatrix}s^2+5s+2&s+5&1\\-3&s^2+5s&s\\-3s&-2s-3&s^2\end{bmatrix}\]
\[G(s)=\frac{1}{s^3+5s^2+2s+3}\begin{bmatrix}1&0&0\end{bmatrix}\operatorname{adj}(sI-A)\begin{bmatrix}0\\0\\10\end{bmatrix}=\frac{10}{s^3+5s^2+2s+3}\]

The poles are \(-4.711\) and \(-0.145\pm j0.785\), all in the left half-plane, and the DC gain is \(10/3=3.33\).

This \(A\) is in phase-variable (companion) form: ones on the superdiagonal and the characteristic coefficients in the bottom row, \(\begin{bmatrix}-a_0&-a_1&-a_2\end{bmatrix}\). Whenever you see that shape, with \(B\) non-zero only in its last entry and \(C=[1\;0\;0]\), you can write the answer immediately:

\[G(s)=\frac{b}{s^3+a_2s^2+a_1s+a_0}=\frac{10}{s^3+5s^2+2s+3}\]

No determinant, no adjugate. Use the lab to convince yourself that the bottom row really is the characteristic polynomial, backwards.

Result
\[G(s)=\frac{10}{s^3+5s^2+2s+3}\]

Poles straight from the state matrix

Without solving the state equation, find the poles of

\[\dot{\mathbf x}=\begin{bmatrix}-2&-1\\-3&-5\end{bmatrix}\mathbf x+\begin{bmatrix}1\\2\end{bmatrix}u(t),\qquad y=\begin{bmatrix}3&2\end{bmatrix}\mathbf x\]

Nise, chapter 4, problem 35, p. 218. Section 4.10.

Walkthrough

The transfer function is \(C(sI-A)^{-1}B\) and the inverse carries \(\det(sI-A)\) in its denominator. So the poles of the system are the roots of

\[\det(sI-A)=0\]

\(B\) and \(C\) never enter: they can only cancel a pole with a zero, never create one.

\[sI-A=\begin{bmatrix}s&0\\0&s\end{bmatrix}-\begin{bmatrix}-2&-1\\-3&-5\end{bmatrix}=\begin{bmatrix}s+2&1\\3&s+5\end{bmatrix}\]
\[\det=(s+2)(s+5)-(1)(3)=s^2+7s+10-3=s^2+7s+7\]
\[s=\frac{-7\pm\sqrt{49-28}}{2}=\frac{-7\pm\sqrt{21}}{2}\;\Rightarrow\;s_1=-1.2087,\quad s_2=-5.7913\]

Two real negative poles: a stable, overdamped system.

For any \(2\times2\) matrix the characteristic polynomial is

\[s^2-\operatorname{tr}(A)\,s+\det(A)\]

Here \(\operatorname{tr}(A)=-7\) and \(\det(A)=10-3=7\), which gives \(s^2+7s+7\) in one line. It also gives a fast stability test for second-order systems: stable exactly when the trace is negative and the determinant is positive.

Result
\[\det(sI-A)=s^2+7s+7,\qquad s_1=-1.2087,\quad s_2=-5.7913\]

Characteristic equation of a 3×3 system

Find the characteristic equation and the poles of

\[\dot{\mathbf x}=\begin{bmatrix}0&2&3\\0&6&5\\1&4&2\end{bmatrix}\mathbf x+\begin{bmatrix}0\\1\\1\end{bmatrix}u(t),\qquad y=\begin{bmatrix}1&2&0\end{bmatrix}\mathbf x\]

Nise, chapter 4, problem 36, p. 218. Section 4.10.

Walkthrough

\[sI-A=\begin{bmatrix}s&-2&-3\\0&s-6&-5\\-1&-4&s-2\end{bmatrix}\]

Expand along the first column: it has a zero in the middle, so only two 2×2 determinants are needed.

\[\det\begin{bmatrix}s-6&-5\\-4&s-2\end{bmatrix}=(s-6)(s-2)-20=s^2-8s-8\]
\[\det\begin{bmatrix}-2&-3\\s-6&-5\end{bmatrix}=10+3(s-6)=3s-8\]

The signs along the first column are \(+,-,+\), and the middle entry is zero:

\[\det(sI-A)=s(s^2-8s-8)+0-1\cdot(3s-8)=s^3-8s^2-8s-3s+8\]
\[\det(sI-A)=s^3-8s^2-11s+8\]
\[s_1=9.1110,\qquad s_2=0.5338,\qquad s_3=-1.6448\]

Two of them are in the right half-plane, so this system is unstable. Two quick checks on the arithmetic: the roots must sum to \(-a_2=8\) (\(9.111+0.534-1.645=8.0\) ✓), and their product must equal \(-a_0=-8\) ✓.

Result
\[\det(sI-A)=s^3-8s^2-11s+8,\qquad s=9.1110,\;0.5338,\;-1.6448\]

Solving the state equation with Laplace transforms

Solve for \(Y(s)\) using the Laplace-transform method, with \(\mathbf x(0)=\mathbf 0\) and \(u(t)=e^{-t}\):

\[\dot{\mathbf x}=\begin{bmatrix}0&1&0\\-2&-4&1\\0&0&-6\end{bmatrix}\mathbf x+\begin{bmatrix}0\\0\\1\end{bmatrix}e^{-t},\qquad y=\begin{bmatrix}1&2&0\end{bmatrix}\mathbf x\]

Nise, chapter 4, problem 38, p. 218. Section 4.10.

Walkthrough

Transforming \(\dot{\mathbf x}=A\mathbf x+B u\) keeps the initial state:

\[\mathbf X(s)=(sI-A)^{-1}\big[\mathbf x(0)+BU(s)\big]\]

Here \(\mathbf x(0)=\mathbf 0\) and \(u(t)=e^{-t}\) gives \(U(s)=\frac{1}{s+1}\), so only the forced part survives.

\[sI-A=\begin{bmatrix}s&-1&0\\2&s+4&-1\\0&0&s+6\end{bmatrix}\]

The last row has two zeros, so expand along it:

\[\det=(s+6)\big[s(s+4)+2\big]=(s+6)(s^2+4s+2)\]

\(B\) is zero except in its last entry, so \((sI-A)^{-1}B\) is the third column of the inverse. Computing just those three cofactors:

\[(sI-A)^{-1}B=\frac{1}{(s+6)(s^2+4s+2)}\begin{bmatrix}1\\s\\s^2+4s+2\end{bmatrix}\]
\[\mathbf X(s)=\frac{1}{s+1}\cdot\frac{1}{(s+6)(s^2+4s+2)}\begin{bmatrix}1\\s\\s^2+4s+2\end{bmatrix}\]

\(y=x_1+2x_2\), so multiply the first entry by 1 and the second by 2 and add:

\[Y(s)=\frac{1+2s}{(s+1)(s+6)(s^2+4s+2)}\]

Factoring the quadratic (\(s=-2\pm\sqrt2\)):

\[Y(s)=\frac{2s+1}{(s+1)(s+6)(s+0.5858)(s+3.4142)}\]

Four distinct real poles means four decaying exponentials:

\[y(t)=A_1e^{-t}+A_2e^{-6t}+A_3e^{-0.5858t}+A_4e^{-3.4142t}\]

Each coefficient is the residue \(A_k=\frac{N(p_k)}{D'(p_k)}\). The slowest pole, \(-0.5858\), dominates the tail; the input's own pole at \(-1\) appears as one of the four terms. The lab plots the total and the individual terms.

Result
\[Y(s)=\frac{2s+1}{(s+1)(s+6)(s^2+4s+2)}\]

Counting eigenvalues without finding them

Determine how many eigenvalues lie in the right half-plane, in the left half-plane and on the \(j\omega\) axis for

\[\dot{\mathbf x}=\begin{bmatrix}0&1&3\\2&2&-4\\1&-4&3\end{bmatrix}\mathbf x+\begin{bmatrix}0\\1\\0\end{bmatrix}u,\qquad y=\begin{bmatrix}1&1&0\end{bmatrix}\mathbf x\]

Nise, chapter 6, problem 50, p. 252. Section 6.5.

Walkthrough

Stability in state space is the same question as before, asked about \(\det(sI-A)\):

\[sI-A=\begin{bmatrix}s&-1&-3\\-2&s-2&4\\-1&4&s-3\end{bmatrix}\]

Expanding along the first row:

\[\det=s\big[(s-2)(s-3)-16\big]+\big[-2(s-3)+4\big]-3\big[-8+(s-2)\big]\]
\[\det(sI-A)=s^3-5s^2-15s+40\]

Two coefficients are negative, which already guarantees at least one root outside the left half-plane. Routh says exactly how many.

\(s^3\)1−15
\(s^2\)−540
\(s^1\)−70
\(s^0\)40
\[b_1=\frac{(-5)(-15)-(1)(40)}{-5}=\frac{35}{-5}=-7\]

The first column runs \(1,\,-5,\,-7,\,40\): two sign changes, so 2 eigenvalues in the right half-plane, 1 in the left, and none on the axis (no zero row appeared).

\[s_1=6.3691,\qquad s_2=1.9133,\qquad s_3=-3.2824\]

Two positive, one negative ✓. The system is unstable — and notice that \(B\) and \(C\) again played no part: stability is a property of \(A\) alone.

Result
\[\text{2 eigenvalues in the right half-plane},\quad\text{1 in the left half-plane},\quad\text{none on the }j\omega\text{ axis}\]
